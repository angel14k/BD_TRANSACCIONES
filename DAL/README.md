BD TRANSACCIONES

API bancaria desarrollada con ASP.NET Core Web API y SQL Server

DESCRIPCION

Este proyecto forma parte de mi práctica de desarrollo backend. Su objetivo es
implementar operaciones bancarias mediante una API REST y una base de datos
relacional.


FUNCIONALIDADES

* Registro de cuentas bancarias.
* Depósitos y Retiros.
* Transferencia entre cuentas.
* Consulta de saldos.
* Consult de movimientos bancarios.


TECNOLOGIAS UTILIZADAS

* C#.
* ASP.NET Core Web API.
* SQL Server.
* ADO.NET con Microsoft.Data.SqlClient.
* Swagger para probar los edpoints.


ARQUITECTURA

El proyecto está organizado por capas para separar las responsabilidades:

* Controllers: reciben las solicitudes HTTP.
* BLL: contiene la lógica del negocio.
* DAL: gestiona el acceso a la base de datos.
* Models: representan las entidades del sistema.
